# Yamtune v2.0

**料理スキルをレベル100にする、あなただけの成長ストーリー**

一人暮らしの20〜40代向けゲーミフィケーション料理スキルアップアプリ

---

## 🎯 コンセプト（v2.0）

> 「料理が苦手」「何を作ればいいかわからない」という一人暮らしの悩みを、RPGのようなレベルアップ体験に変換。

**20週間（約4ヶ月）で「あなた自身のレベル100」を達成**し、料理の基礎を習得しながら、栄養バランスの取れた時短料理を作れるようになる物語形式の成長体験を提供します。

---

## 📝 v1.0からの変更点

**旧コンセプト（v1.0）**: 子どもの好き嫌い克服サポートアプリ（家族向け）

**新コンセプト（v2.0）**: 料理スキルアップゲーム（一人暮らし向け）

**変更理由**: 市場調査の結果、一人暮らし向け市場の方が約10倍大きく、継続利用率も高いため。詳細は[市場調査レポート](./docs/recipe-app-market-research-2025.md)と[プロジェクト設計書](./docs/project-redesign-cooking-skill-game.md)を参照。

## 🎮 主な特徴（v2.0）

### ゲーミフィケーション
- 📈 **レベル1→100**: 週5日の料理でレベル5ずつ成長
- 🏆 **バッジ・実績システム**: 習得スキルを可視化
- ⭐ **経験値（XP）**: 料理完了、記録投稿、スキル習得でXP獲得
- 📖 **ストーリー形式**: 見習い料理人→マスター料理人への成長物語

### パーソナライゼーション
- 🔧 **保有調理器具**: あなたの持っている器具で作れるレシピのみ提案
- ⏱️ **可処分時間**: 平日15分、休日60分など、あなたの時間に合わせたレシピ
- 🥗 **食の制約・好み**: アレルギー、苦手な食材を考慮

### 週次カリキュラム
- 📅 **自動献立生成**: 毎週レベルに応じた5日分のレシピを自動生成
- 🛒 **買い物リスト**: 必要な食材を自動リスト化
- 📚 **スキル習得**: 包丁の使い方、火加減、味付けなど段階的に学習

### 生活支援
- 🍱 **作り置き対応**: 平日忙しい人向けに週末作り置きを提案
- ❄️ **冷蔵庫管理**: 食材スキャン、賞味期限アラート
- 💰 **節約モード**: 予算内で栄養バランスの取れた食事

## セットアップ

### 前提条件

- Node.js 20以上
- npm または yarn

### インストール

1. リポジトリをクローン
```bash
git clone <repository-url>
cd Yamtune
```

2. 依存パッケージをインストール
```bash
npm install
```

3. 環境変数を設定

`.env.example`を`.env.local`にコピーして、必要な値を設定してください。

```bash
cp .env.example .env.local
```

以下の値を設定します:

- `NEXT_PUBLIC_SUPABASE_URL`: Supabaseプロジェクト URL
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`: Supabase Anon Key
- `SUPABASE_SERVICE_ROLE_KEY`: Supabase Service Role Key
- `OPENAI_API_KEY`: OpenAI API Key（Vision + Chat機能）
- `KLING_ACCESS_KEY`: Kling AI Access Key（画像生成）
- `KLING_SECRET_KEY`: Kling AI Secret Key（画像生成）

### Supabaseのセットアップ

1. [Supabase](https://supabase.com)でプロジェクトを作成
2. データベーススキーマを作成（仕様書の「DATABASE SCHEMA」セクションを参照）
3. APIキーを取得して`.env.local`に設定

### 開発サーバーの起動

```bash
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開きます。
