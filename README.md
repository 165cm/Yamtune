# Yamtune

好き嫌い克服サポートアプリ - 子どもの好き嫌いを克服する栄養サポートレシピアプリ

## 概要

Yamtuneは、2〜10歳の好き嫌いの多い子どもを持つ母親向けの栄養サポートレシピアプリです。食品パッケージをスキャンして栄養データを取得し、AIが栄養バランスの取れたレシピを生成します。

## 主な機能

- 📸 **商品スキャン機能（OCR）**: スマホカメラで食品パッケージを撮るだけで、栄養情報を自動で読み取ります。
- 🤖 **AI レシピ生成**: お子様の好き嫌いや栄養バランスを考慮して、食べやすいレシピをAIが提案します。
- 👨‍👩‍👧‍👦 **家族・子ども管理**: お子様ごとのプロフィール（好き嫌いやアレルギー情報）を登録・管理できます。
- 📊 **成長記録と克服進捗**: 好き嫌い克服の過程を記録し、成長を見える化します。
- 🍳 **調理記録機能**: 作った料理や食べた反応を記録に残せます。
- 🌐 **PWA対応**: アプリのようにホーム画面に追加して手軽に使えます。
