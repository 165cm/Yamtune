# UI ラフ画像 発注指示書

> 目的：女性ユーザーに最適化されたシンプルで使いやすい2つのアプリの主要画面を、ラフ（手描きまたはワイヤーフレーム）で起こしていただくための仕様書です。

---

## 1. プロジェクト概要

### 構成
2つの連携するスマホアプリ（PWA / iPhone・Android）を開発します。

| アプリ名 | 役割 | アイコン候補 |
|---|---|---|
| **Yamtune（ヤムチューン）** | レシピ管理＋子どもの好き嫌い克服サポート | 🍳 / お皿 |
| **Sokotune（ソコチューン）※仮** | 食材の在庫管理＋底値（最安値）管理＋買い物リスト | 🛒 / 冷蔵庫 |

※ 2アプリは同じアカウントで連携し、データを共有します。

### ターゲットユーザー
- **30〜40代の女性**（主婦・働く母親）
- スマホはあまり得意ではないが、Instagram・LINE は日常的に使う
- 子ども（2〜10歳）の食事を毎日作っている
- 節約志向だが家計簿アプリは挫折経験あり

## 2. デザインの基本方針

### トーン＆マナー
| 要素 | 指定 |
|---|---|
| 全体の印象 | やさしい / あたたかい / 清潔感 / ナチュラル |
| 避けるもの | カラフルすぎる / ゲーム的 / 業務システム的 / 男性的 |
| 参考アプリ | クックパッドマート、タベリー、Notion Calendar、北欧、暮らしの道具店アプリ |

### カラーパレット（推奨）
```
ベース      : #FFFBF5（オフホワイト・温かみ）
メイン      : #F5B5A8（くすみピンク／サーモン）
アクセント  : #88B5A3（くすみグリーン／セージ）
警告        : #E8A87C（テラコッタ）
テキスト    : #4A4238（ダークブラウン）※純黒は使わない
```

### タイポグラフィ
- **日本語**：Noto Sans JP / ヒラギノ角ゴ / 游ゴシック（柔らかめのウェイト）
- **数字**：丸みのあるサンセリフ
- **フォントサイズ**：小さい文字を避ける（最小14pt、本文16pt以上）

### UI ルール
- **角丸を多用**（16〜24px）
- **余白をたっぷり**（窮屈さを避ける）
- **アイコンは線画＋手描き風**（細すぎない）
- **写真をメインビジュアルに**（テキストUI最小化）
- **1画面1機能**（モーダル多用しない）
- **ボタンは大きめ**（タップ領域 56px 以上）

## 3. 発注対象：必要なラフ画像一覧

### 🍳 Yamtune（レシピアプリ）— 全6画面

#### Y-01. ホーム画面
**目的**：今日何を作ろうかなと迷ったときに、答えがすぐ出る画面

**配置要素**
- 上部：挨拶（「こんにちは、〇〇さん」）+ 子どものアバター
- 中央：「今ある食材で作れるレシピ」横スクロールカード（写真大）
- その下：「最近作ったレシピ」横スクロールカード
- 下部：「献立を考える」大きなCTAボタン
- フッター：タブバー（ホーム / レシピ / 家族 / 設定）

**ポイント**
- 写真の比率を大きく
- カードは料理写真＋料理名のみ（栄養数値は出さない）

---

#### Y-02. レシピ一覧画面
**目的**：保存したレシピをサッと探す

**配置要素**
- 上部：検索バー（虫眼鏡アイコン + プレースホルダー「料理名や食材で検索」）
- フィルタチップ：[和風][洋風][中華][時短][子ども喜ぶ]（横スクロール）
- ギャラリー2カラム：料理写真 + 料理名 + 調理時間アイコン
- 右下：浮かぶ「+」FABボタン（新規レシピ追加）

**ポイント**
- Pinterest 風グリッド
- お気に入りはハートマークを写真左上にオーバーレイ

---

#### Y-03. レシピ詳細画面
**目的**：作りながら見る画面（手が濡れていてもOK）

**配置要素**
- 最上部：料理写真（全画面幅・正方形）
- 料理名（大きく）+ ⭐お気に入りボタン
- 情報バッジ3つ：[⏱️ 20分][👥 4人前][😊 簡単]
- セクション①「材料」：箱型カードに表組み（食材名 / 分量）
  - 在庫がない食材は **赤いドット** で表示
  - タップで「買い物リストに追加」
- セクション②「作り方」：番号付きステップ + 各ステップに小さなイラスト
- 下部固定ボタン：「作った！」（押すと在庫減算 + 記録）

---

#### Y-04. 献立提案画面（AI生成）
**目的**：今ある食材から AI が3つレシピを提案

**配置要素**
- 上部：「今日の気分は？」選択チップ
  - [サッと作りたい][栄養重視][子ども喜ぶ][余り物消費]
- 中央：AIが提案する3つのカード（縦並び）
  - 各カードに：料理写真 / 料理名 / 必要な食材（在庫充足率バー）
- 下部：「もう一度提案」ボタン

---

#### Y-05. 家族・子ども管理画面
**目的**：誰が何が好き/嫌いかを登録

**配置要素**
- 上部：家族カード（メンバーアバター横並び）
- 中央：選択中の子どもの情報
  - 写真 / 名前 / 年齢
  - 「好きな食べ物」緑色チップ
  - 「苦手な食べ物」オレンジ色チップ
  - 「克服した食べ物」⭐マーク付きチップ
- 下部：「+ 食べ物を追加」ボタン

---

#### Y-06. 調理記録画面（モーダル）
**目的**：作った後の感想を簡単記録

**配置要素**
- 「お子さんの反応は？」絵文字4択（😍😊😐😢）大きめタップ
- 「どれくらい食べた？」スライダー（全部/半分/少し/食べなかった）
- 「克服できた食べ物があれば教えてください」（任意）
- 「保存」ボタン

---

### 🛒 Sokotune（在庫＆底値アプリ）— 全6画面

#### S-01. ホーム画面
**目的**：冷蔵庫を開けるより早く中身がわかる

**配置要素**
- 上部：「在庫サマリー」3カードを横並び
  - [🥬 野菜 12個][🍖 肉 3個][🥫 調味料 25個]
- 中央：「もうすぐ切れそう」リスト（赤・黄バッジ付き）
- その下：「お買い得情報」（底値更新があった食材）
- 下部固定：「買い物リストへ」CTAボタン

---

#### S-02. 在庫一覧画面
**目的**：何があるかをパッと見渡す

**配置要素**
- 上部：カテゴリタブ（横スクロール）
  - [すべて][生鮮][肉魚][調味料][主食][保存食][飲料][お菓子][雑貨]
- メイン：3カラムグリッド
  - 各セルに：商品写真（正方形）+ 食材名 + 在庫数バッジ
  - 在庫切れは写真をグレースケール + 赤い「✕」オーバーレイ
- 右下：「+」FABボタン

**ポイント**
- 写真ファースト（食材名は2行目）
- 写真がないものは絵文字（🥕🥩🍞）でフォールバック

---

#### S-03. 食材詳細画面
**目的**：その食材の在庫・価格履歴・どこで買うのが安いか

**配置要素**
- 上部：商品写真（横全幅）
- 食材名 + カテゴリチップ
- 在庫数（大きな数字 + ＋／−ボタン）
- セクション①「底値情報」
  - 「最安値 ¥98 / 100g（業務スーパー〇〇店）」（強調表示）
  - 過去の購入履歴ミニ折れ線グラフ
- セクション②「店舗別価格」表
  - 店舗名 / 価格 / 日付（最新3件）
- セクション③「使われているレシピ」（Yamtune との連携）
  - 横スクロールカード

---

#### S-04. 買い物リスト画面
**目的**：スーパーで使う画面（片手・歩きながら）

**配置要素**
- 上部：「今日の買い物」タイトル + 合計予想金額
- リスト：チェックボックス + 食材名（大きい）+ 想定価格（小さい）
  - カテゴリごとにグルーピング（売り場順に並ぶ）
- チェック済みは取り消し線 + 薄く
- 下部：「すべて買えた」ボタン → 一括で在庫追加モーダルへ

**ポイント**
- 文字を最大限大きく（スーパーで見やすく）
- スクロール最小化

---

#### S-05. 商品追加画面（カメラ）
**目的**：パッケージを撮るだけで登録完了

**配置要素**
- 上半分：カメラビュー（四角いガイド枠）
- 下半分：「商品をフレーム内に収めて撮影してください」案内文
- 中央下：大きな丸い撮影ボタン
- 左下：ギャラリーから選択
- 右下：手入力に切り替え

**撮影後フロー（次画面）**
- AI が自動認識した「商品名 / カテゴリ / 推定価格」
- ユーザーは値を確認・修正するだけ
- 「保存」で完了

---

#### S-06. 価格記録画面（モーダル）
**目的**：レシート見ながらポンポン入力

**配置要素**
- 「どこで買いましたか？」店舗選択（よく行く店上位3つを大ボタン）
- 食材リスト（既存在庫から多選択）
- 各食材に：価格 / 容量 入力欄（テンキー）
- 「底値更新！」のとき緑色バッジが出現する演出
- 下部：「記録する」ボタン

## 4. 共通コンポーネント（先に1セット起こしてほしい）

| コンポーネント | 仕様 |
|---|---|
| ボタン（プライマリ） | 高さ56px、角丸16px、メインカラー塗り |
| ボタン（セカンダリ） | アウトライン、メインカラー線 |
| 入力欄 | 高さ48px、角丸12px、薄いボーダー |
| カード | 角丸20px、ドロップシャドウ薄め |
| バッジ（カテゴリチップ） | 角丸9999（pill）、パステル背景 |
| アバター | 円形、ボーダー2pxくすみピンク |
| FAB（+ボタン） | 直径56px、メインカラー、影付き |
| タブバー | 4タブ、選択中はメインカラー＋ラベル表示 |
| 空状態（empty） | 手描きイラスト＋やさしいメッセージ |
