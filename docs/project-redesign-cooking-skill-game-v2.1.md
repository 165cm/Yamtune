## 🎯 プロジェクト概要

### コンセプト
> 「料理スキルで悪を倒し、世界を救う勇者になろう」

一人暮らしの20〜40代向けに、**本格RPG体験**を取り入れた料理スキルアップアプリ。20週間（約4ヶ月）で「あなた自身のレベル100」を達成し、**ファストフード魔人**や**デザートドラゴン**などの敵を倒しながら、料理の基礎を習得。

Lv100達成後は**オープンワールド**へ。世界中のプレイヤーとランキングで競い、さらなる高みを目指す。

### ビジョン
「料理が苦手」「何を作ればいいかわからない」という一人暮らしの悩みを、**ドラクエのような冒険RPG体験**に変換。料理を「義務」から「世界を救う使命」に変え、継続することで確実に強くなる実感を得られる。

## 🎨 ファンタジーステータスシステム（栄養素の置き換え）

### 5大ステータス

法的リスク回避 + ファンタジー感を出すため、栄養素を独自ステータスに変換：

| 栄養素 | ファンタジー名 | アイコン | 説明 | 単位変換 |
|--------|--------------|---------|------|---------|
| タンパク質 | **チカラのもと** | 💪 | 筋肉と力の源 | g → ポイント（そのまま） |
| 炭水化物 | **ゲンキのもと** | ⚡ | エネルギーと活力 | g → ポイント（そのまま） |
| 脂質 | **スタミナのもと** | 🔋 | 持久力と体力 | g → ポイント（そのまま） |
| ビタミン | **マモリのもと** | 🛡️ | 防御力と免疫 | 種類数 → ポイント |
| ミネラル | **ケンコウのもと** | ✨ | 健康と回復力 | 種類数 → ポイント |

### ステータス表示例
```
今日の料理「鶏の照り焼き」

獲得ステータス:
💪 チカラのもと: 28pt (タンパク質 28g)
⚡ ゲンキのもと: 45pt (炭水化物 45g)
🔋 スタミナのもと: 12pt (脂質 12g)
🛡️ マモリのもと: 8pt (ビタミン 8種類)
✨ ケンコウのもと: 5pt (ミネラル 5種類)

バランススコア: ⭐⭐⭐⭐☆ (4/5)
```

### バランススコアの計算
```javascript
バランススコア = 5大ステータスの偏りを評価

例:
チカラ: 30pt, ゲンキ: 50pt, スタミナ: 15pt, マモリ: 8pt, ケンコウ: 5pt
→ 偏差が小さい = 高スコア（⭐⭐⭐⭐⭐）

チカラ: 5pt, ゲンキ: 80pt, スタミナ: 3pt, マモリ: 2pt, ケンコウ: 1pt
→ ゲンキに偏り = 低スコア（⭐⭐☆☆☆）
```

### なぜファンタジー化するのか？
1. **法的リスク回避**: 正確な栄養計算ができない個人開発でも、「ファンタジー世界のステータス」なら許容範囲
2. **ゲーム感UP**: 「タンパク質28g」より「チカラのもと28pt」の方がRPG感がある
3. **誤差の許容**: AIが多少間違えても「ファンタジーだから」で通る
4. **わかりやすさ**: 栄養知識がなくてもステータス=強さとして理解しやすい

## 🚨 リスク＆対策（v2.1更新版）

### リスク1: 6週間開発がオーバーラン
**対策**:
- MVP Coreに絞る（AI報酬・世界ランクは後回し）
- 毎週末に進捗レビュー、遅延があれば即スコープカット
- Phase 2機能は運用後追加（アジャイル）

### リスク2: AI生成コストが高騰
**対策**:
- Phase 1ではAI報酬なし、Phase 2で段階導入
- 報酬は週1回限定（5日連続達成時のみ）
- コスト上限設定（月¥50,000まで）

### リスク3: 敵キャラが幼稚に見える
**対策**:
- デザインにこだわる（イラストレーター外注検討）
- ストーリーテキストで世界観を補強
- ベータユーザーにフィードバック取得

### リスク4: ファンタジーステータスが分かりにくい
**対策**:
- オンボーディングで丁寧に説明
- 「栄養素を見る」切り替えボタン設置（上級者向け）
- AIコーチが解説

### リスク5: 継続率が上がらない
**対策**:
- 敵キャラバトルで「倒したい」欲求を刺激
- 週末のリマインダー強化
- ソーシャル要素（世界ランク）でモチベーション維持
